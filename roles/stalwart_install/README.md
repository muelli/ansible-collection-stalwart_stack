# stalwart_install

Install pinned Stalwart server and stalwart-cli binaries, systemd unit and data store config.

Part of the collection `muelli.stalwart_stack`; the role is used as
`muelli.stalwart_stack.stalwart_install`. The repository README describes how the five
roles fit together and the order they run in.

## Variables

Every variable, with its default and a comment, is in
[`defaults/main.yml`](defaults/main.yml).
