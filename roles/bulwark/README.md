# bulwark

Bulwark webmail as a Podman Quadlet container behind the fronting Caddy, pointed at Stalwart over its public URL.

Part of the collection `muelli.stalwart_stack`; the role is used as
`muelli.stalwart_stack.bulwark`. The repository README describes how the five
roles fit together and the order they run in.

## Variables

Every variable, with its default and a comment, is in
[`defaults/main.yml`](defaults/main.yml).
