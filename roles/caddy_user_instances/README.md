# caddy_user_instances

Socket-activated per-user Caddy instances reachable from the fronting Caddy through restricted UNIX sockets.

Part of the collection `muelli.stalwart_stack`; the role is used as
`muelli.stalwart_stack.caddy_user_instances`. The repository README describes how the five
roles fit together and the order they run in.

## Variables

Every variable, with its default and a comment, is in
[`defaults/main.yml`](defaults/main.yml).
