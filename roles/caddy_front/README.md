# caddy_front

Caddy as the single TLS terminator for Stalwart's web endpoints, per-user Caddy instances and plain sites, with certificate sync to Stalwart.

Part of the collection `muelli.stalwart_stack`; the role is used as
`muelli.stalwart_stack.caddy_front`. The repository README describes how the five
roles fit together and the order they run in.

## Variables

Every variable, with its default and a comment, is in
[`defaults/main.yml`](defaults/main.yml).
