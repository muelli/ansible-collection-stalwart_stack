# stalwart_config

Declarative Stalwart configuration (listeners, domains, DNS providers, relays, routing) applied through stalwart-cli.

Part of the collection `muelli.stalwart_stack`; the role is used as
`muelli.stalwart_stack.stalwart_config`. The repository README describes how the five
roles fit together and the order they run in.

## Variables

Every variable, with its default and a comment, is in
[`defaults/main.yml`](defaults/main.yml).
